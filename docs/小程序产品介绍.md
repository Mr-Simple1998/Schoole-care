# 清禾家塾管理系统 · 小程序产品介绍

> 托管 / 课后辅导机构的一站式移动管理工具
> 校长、校区负责人、教师手机端随时管理学生、收费、考勤与积分

---

## 一、产品简介

清禾家塾管理系统小程序是「清禾家塾管理系统」的移动端，面向**托管机构、课后辅导机构**的日常经营管理场景。机构老板、校区负责人与教师无需守在电脑前，打开微信即可完成学生管理、收费记账、考勤打卡、积分激励等核心工作；数据与 PC 后台实时同步，一处录入、多端一致。

小程序支持微信授权登录，首次绑定账号密码后自动登录，操作门槛低、上手快。

---

## 二、核心功能

### 🏠 一站式工作台
- 今日在读学生、出勤、收入、欠费等经营数据一目了然
- 收费到期、课时到期、新学员入学一周未交费等**主动提醒**
- 教师上下班打卡入口 + 全体学生考勤月历
- 常用功能快捷入口，一步直达

### 🧑‍🎓 学生管理
- 学生档案：基本信息、所属校区、负责教师、学科与剩余课时
- 每日打卡 / 补卡：正常、迟到、早退、缺勤、请假多状态记录
- 本月考勤月历：按学生查看每日打卡情况，漏卡可补
- 学习档案：成绩记录、作业布置与批改、课堂表现评分，随时掌握学情

### 💰 收费管理
- 收费流水与欠费明细，谁欠费、欠多少一目了然
- 新增收费、账单生成、分期缴费
- 续费提醒、退费 / 减免登记，账目清晰可追溯

### 🏆 积分激励
- 学生积分加扣，排行榜实时更新
- 配合奖品兑换，激发学生积极性，机构口碑加分

### 👩‍🏫 教师与团队
- 教师账号管理：新增、编辑、停用 / 启用、重置密码
- 上下班时间设置与打卡考勤汇总
- 教师离职一键交接：名下学生自动暂存校区，数据完整保留

### 🏫 校区管理
- 多校区经营卡片：收入、支出、结余、在读学生、今日打卡
- 手工收支登记与明细流水
- 校区负责人多选设置；负责人离职后校区数据原样保留、无缝接管

### 📚 学科与课时
- 学科 / 非学科灵活分类，支持计次课程
- 课时核销与剩余次数进度，家长续费有据可依

### 🏢 平台管理（面向运营方）
- 机构开户、计费 / 续费、开户流水
- 全平台运营总览：机构数、学生数、收入、待缴金额等

## 三、角色与权限

| 角色 | 主要权限 |
|------|----------|
| 平台管理员 | 机构开户、续费、平台运营统计 |
| 总校长 | 全机构数据：收费、教师、学科、校区、积分等 |
| 校区负责人 | 所辖校区管理：学生、收费、收支、负责人 |
| 教师 | 负责学生的档案、打卡、成绩、作业、课堂表现 |

多角色、多校区**数据自动隔离**，各司其职、互不越权。

---

## 四、产品亮点

- **微信生态，即用即走**：无需下载安装，微信授权一键登录
- **随时随地管理**：老板查账、老师打卡不再受电脑约束
- **多端数据同步**：与 PC 后台同一套系统，账目、档案实时一致
- **智能提醒**：欠费、课时到期、未交费新生主动推送，不漏一单
- **权限清晰可控**：角色分级 + 校区隔离，适合连锁 / 多校区机构
- **数据安全留存**：员工离职、账号变更不影响机构数据，交接零损失

---

## 五、适用场景

- 午托、晚托、课后辅导机构的**日常管理**
- 校长 / 老板**外出时查收经营数据、处理收费**
- 教师**课后为学生补打卡、记录成绩与表现**
- 连锁机构、多校区**总部与分校协同管理**
- 平台方**统一开户、续费与运营监管**
