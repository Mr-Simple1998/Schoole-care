# 超级管理员系统

一个面向教学机构（托管中心）的**多机构管理系统**，包含**平台超级管理员端**、**校长端**和**教师端**，支持机构开户、账号到期管理、学生学习情况、收费管理、积分奖励等核心业务。

## 技术栈

- 前端：Vue 3 + Vite + Element Plus + ECharts + Pinia + Vue Router
- 后端：Python FastAPI + SQLAlchemy
- 数据库：SQLite（开发）/ MySQL（上云部署）
- 认证：JWT Token + bcrypt 密码加密

## 功能清单

### 登录认证
- 校长 / 教师账号密码登录，JWT 鉴权
- 角色权限隔离：教师端隐藏收费管理、教师管理等校长专属功能；后端接口双重校验
- **多角色体系**：平台超级管理员（开户）、校长、教师三级权限，机构间数据完全隔离

### 平台超级管理员端
- **机构开户管理**：为新校长开户（创建机构 + 校长账号），开户后数据归零
- **机构交费**：开户时录入计费方式（按年/按次阶段/自定义）、交费金额、交费时间段（半年/一年），到期日期由开户当日自动推算并显示在状态栏
- **交费/续费**：为机构续费选择交费时间段，到期日在原到期日基础上自动顺延，累计交费金额自动累加；支持查看每个机构的流水明细
- **账号到期提醒**：自动识别「即将到期（提前7天）」和「已到期」机构，列表高亮标注
- **开户流水统计**：总交费金额、按机构汇总、按月交费趋势（柱状图）、待收款/已到期机构列表（可一键续费）

### 校长端
- **账号到期提醒**：登录工作台后，若机构账号即将到期或已到期，顶部显示醒目提醒横幅，提示联系平台续费
- **工作台**：在读学生数、本月收入、待缴欠费、今日考勤等统计 + 近14天收入趋势图 + 学科学生分布图 + 缴费到期提醒（提前5天推送，含负责教师）
- **收费管理**：收费流水记录（支持选择缴费时间段：一月/半学期/一年，自动推算到期日）、账单生成、欠费/未缴提醒、退费/减免处理
- **学费分期**：为学费创建分期计划（自动生成各期还款记录）、逐期缴纳、分期详情与进度追踪
- **学科管理**：学科分类（学科类：语文/数学/英语/托管；非学科类：魔方/书法/画画/轮滑）的增删改查、启停用、排序
- **教师管理**：创建教师账号、为教师设置多个所属学科、编辑教师学科、停用账号、查看账号列表、重置教师密码
- **学生管理**：学生信息增删改查（含负责教师显示），可为学生设置多个所属学科并支持按学科筛选；删除学生后校长端/教师端同步隐藏，并清除其积分，但保留收费管理历史记录
- **个人资料**：点击右上角头像可修改本人姓名、电话、邮箱、头像、登录密码

### 教师端
- **学生学习档案**：学习成绩记录与趋势图、考勤打卡、作业管理、课堂表现；头部展示学生所属学科标签
- **学生管理**：查看学生列表（含学科标签、负责教师）、按学科筛选、新增学生会自动归属到当前教师名下并可同步到校长端；删除学生后与校长端同步隐藏并清除积分
- **成绩单导出**：按学生导出成绩单（CSV，UTF-8 BOM，Excel 可直接打开）
- **考勤统计报表**：考勤状态占比、按学生汇总、每日明细，出勤率与考勤构成饼图
- **积分奖励系统**：积分加扣、积分排行榜、奖品管理、积分兑换（下拉选择学生）
- **缴费到期提醒**：教师端工作台仅展示"在读学生/今日考勤"统计（无收入、欠缴费），可就本人负责学生的缴费到期情况（提前5天）提醒家长续费

## 快速启动（本地开发）

### 方式一：一键启动脚本
双击项目根目录的 `start.bat`，脚本会自动完成环境检查、依赖安装、数据库初始化，并启动前后端服务。

### 方式二：手动启动

#### 1. 后端
```bash
cd backend
# 创建虚拟环境（首次）
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
# 初始化数据库（创建默认校长账号）
.venv\Scripts\python -m app.seed_admin
# 启动服务
.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

#### 2. 前端
```bash
cd frontend
npm install
npm run dev
```

## 上云部署指南（先本地后上云）

当前使用 SQLite 适合本地/单机使用。要真正"上架"供多教师、多校区通过网络访问，建议切换到 MySQL 并部署到云服务器。

### 1. 切换数据库到 MySQL

1. 在云服务器安装 MySQL，创建数据库 `tuoguan`。
2. 在 `backend/app/config.py` 中修改 `database_url`：
   ```python
   database_url = "mysql+pymysql://用户名:密码@数据库地址:3306/tuoguan?charset=utf8mb4"
   ```
3. 安装 PyMySQL：`pip install pymysql`

### 2. 部署到云服务器

- 后端：使用 `uvicorn` + `gunicorn`（推荐 `uvicorn --workers 4`），或 Nginx 反向代理到 8000 端口。
- 前端：执行 `npm run build` 生成静态文件，由 Nginx 托管，并配置 `/api` 反向代理到后端。

### 3. 安全配置（重要）

- 修改 `SECRET_KEY`（`backend/app/security.py`）为随机长字符串。
- 修改默认校长密码 `admin123`。
- 数据库账号使用独立、强密码，不要用 root。

### 4. 数据备份

- SQLite：定期备份 `tortoise.db` 文件。
- MySQL：使用 `mysqldump` 定期备份。
